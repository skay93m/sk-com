## Incident Response Plan

### If a Secret is Accidentally Committed

**Immediate Actions:**
1. **Rotate the secret immediately** - Generate new DJANGO_SECRET_KEY, update in Render
2. **Revoke the exposed secret** - Mark as compromised
3. **Remove from git history** - Use `git filter-branch` or `BFG Repo Cleaner`
4. **Force push** - Update remote repository
5. **Notify** - If public repo, assume secret is compromised

**Prevention:**
- Use pre-commit hooks to scan for secrets
- Regularly audit commits for sensitive data
- Keep .gitignore up to date

### Dependency Vulnerability

**Actions:**
1. Review security advisory
2. Update affected dependency: `uv sync --upgrade`
3. Test application
4. Deploy update
5. Document in CHANGELOG
