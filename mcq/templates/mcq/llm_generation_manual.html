Overview

The LLM Question Generation system allows you to leverage AI language models to create multiple-choice questions quickly and efficiently, while maintaining quality through a structured review process.

Benefits
  • Speed: Generate multiple questions in seconds
  • Consistency: Standardized format and structure
  • Quality Control: Manual review before database entry
  • Flexibility: Works with any LLM (ChatGPT, Claude, Gemini, etc.)
Key Features
  • Automatic parsing of various response formats
  • Topic tagging and difficulty assignment
  • Individual question review and editing
  • Seamless integration with existing MCQ system

Complete Workflow

1. Create Prompt

Design a detailed prompt specifying the topic, number of questions, difficulty level, and format requirements.

2. Get LLM Response

Copy your prompt to your preferred LLM, get the response, and paste it back into the system.

3. Review & Edit

Review each parsed question, edit if necessary, assign topics, and approve or reject each one.

4. Add to Database

Approved questions are automatically converted to MCQs and added to your study database.

Step 1: Creating Effective Prompts

Key Components of a Good Prompt
  1. Topic specification: Clearly define the subject matter
  2. Quantity: How many questions you want
  3. Difficulty level: Beginner, intermediate, advanced
  4. Format requirements: Multiple choice with 4 options
  5. Answer explanations: Request explanations for learning
  6. Context: Target audience or learning objectives
Prompt Templates

Generate [NUMBER] multiple choice questions about [TOPIC].

Requirements:
- Each question should have 4 answer choices (A, B, C, D)
- Only one correct answer per question
- Include explanations for both correct and incorrect answers
- Difficulty level: [BEGINNER/INTERMEDIATE/ADVANCED]
- Target audience: [DESCRIPTION]

Format each question as:
Question: [Question text]
A) [Option A]
B) [Option B] 
C) [Option C]
D) [Option D]
Correct Answer: [Letter]
Explanation: [Why this answer is correct and others are wrong]

Create [NUMBER] multiple choice questions about [TOPIC].
Please respond with a JSON array in this exact format:

[
  {
    "question": "Your question text here",
    "choices": [
      {"text": "Option A text", "is_correct": false, "explanation": "Why this is wrong"},
      {"text": "Option B text", "is_correct": true, "explanation": "Why this is correct"},
      {"text": "Option C text", "is_correct": false, "explanation": "Why this is wrong"},
      {"text": "Option D text", "is_correct": false, "explanation": "Why this is wrong"}
    ],
    "difficulty": 2,
    "explanation": "General explanation of the concept tested"
  }
]

Requirements:
- Difficulty: 1 (Recall), 2 (Application), 3 (Reasoning)
- Target audience: [DESCRIPTION]
- Focus on: [SPECIFIC CONCEPTS]

Step 2: Working with LLMs

Recommended LLMs

Great for structured responses and following format instructions

Claude

Excellent for detailed explanations and educational content

Gemini

Good for technical topics and factual accuracy

Best Practices
  • Be specific: The more detailed your prompt, the better the output
  • Use examples: Show the LLM the exact format you want
  • Iterate: If the first response isn't perfect, refine your prompt
  • Copy everything: Include the entire LLM response, not just parts

Step 3: Reviewing Generated Questions

Review Criteria
What to Look For
  • Clear, unambiguous question text
  • Only one correct answer
  • Plausible distractors (wrong answers)
  • Appropriate difficulty level
  • Factual accuracy
  • Good explanations
Red Flags
  • Multiple correct answers
  • No clearly correct answer
  • Confusing or poorly worded questions
  • Factual errors
  • Too easy or too difficult for intended level
  • Obvious or silly distractors
Review Status Options
Status When to Use What Happens
Approved Question is ready to use as-is Automatically added to MCQ database
Needs Edit Question has potential but needs fixes Marked for manual editing later
Rejected Question has serious issues Not added to database
Pending Not yet reviewed Waiting for review

Supported Response Formats

The system can automatically parse various response formats from LLMs:

JSON Format
[
  {
    "question": "What is Python?",
    "choices": [
      {"text": "A snake", "is_correct": false},
      {"text": "A programming language", "is_correct": true},
      {"text": "A type of coffee", "is_correct": false},
      {"text": "A calculator", "is_correct": false}
    ],
    "difficulty": 1,
    "explanation": "Python is a popular programming language"
  }
]
Text Format
Question 1: What is Python?
A) A snake
B) A programming language
C) A type of coffee  
D) A calculator
Correct Answer: B

Question 2: Which symbol starts a comment?
A) //
B) #
C) /*
D) --
Correct Answer: B
Parser Intelligence

The system automatically detects the format and extracts questions, choices, and answers. It handles variations in formatting, numbering schemes, and common patterns used by different LLMs.

Prompt Examples by Subject

Generate 5 multiple choice questions about Python data structures (lists, dictionaries, sets, tuples).

Requirements:
- Each question should test practical knowledge
- Include code examples where appropriate
- 4 answer choices per question
- Difficulty: Intermediate (6 months experience)
- Include explanations that help reinforce learning

Focus areas:
- List comprehensions and methods
- Dictionary operations and methods
- Set operations and use cases
- Tuple immutability and unpacking

Create 8 multiple choice questions about cellular respiration for high school biology students.

Requirements:
- Cover all three stages: glycolysis, Krebs cycle, electron transport
- Include questions about ATP production, location of processes, and reactants/products
- 4 answer choices each with explanations
- Mix of recall and application questions
- Avoid overly technical terminology

Learning objectives:
- Understand the overall purpose of cellular respiration
- Identify inputs and outputs of each stage
- Recognize the importance of oxygen in the process
- Connect to real-world applications (exercise, metabolism)

Troubleshooting Common Issues

Problem Cause Solution
No questions parsed Response format not recognized Check that questions are clearly numbered and formatted. Try a more structured prompt.
Wrong number of choices LLM didn't follow instructions Be more explicit about requiring exactly 4 choices. Include an example in your prompt.
No correct answers marked Answer indicators not recognized Ask for "Correct Answer: A" format or use JSON format for precision.
Questions too easy/hard Difficulty level not clear in prompt Be more specific about target audience and provide context about their knowledge level.
Poor quality distractors LLM needs guidance on good wrong answers Ask for "plausible but incorrect" choices and specify they should test understanding.
Important Notes
  • Always review: LLMs can make factual errors or create ambiguous questions
  • Check duplicates: Make sure you're not creating questions too similar to existing ones
  • Test difficulty: Consider if questions match your intended learning objectives
  • Save your prompts: Good prompts can be reused and refined for future sessions
