1. I have a website. I have had several versions of it. None of them lasted very long.

2. The first few attempts were built on platforms I did not control. When I stopped paying attention, they fell into disrepair. A website, I have learned, is like a garden. Leave it unattended and it becomes an embarrassment.

3. This version is different. I built it myself.

4. The backend is Python, using the Django framework. There is no database. Every post I write is a text file sitting in a folder in the same repository as the code. When I push a change to GitHub, the site updates automatically. I find this arrangement satisfying. There are no moving parts that I do not understand.

5. I was inspired by [Spencer](https://spencer.wtf). His site was so simple it made me feel guilty about every complicated thing I had ever built. One column. Black text on white background. A list of writing. Nothing else. I decided I wanted something like that.

6. I have spent most of my career as a pharmacist. I have also studied law, done some research, worked in a biotech company, and most recently sat an actuarial examination (IFOA CS1 if you must know) — results are still pending. I have many interests. This is sometimes a problem. People expect you to be one thing. A website full of unrelated pursuits looks like confusion.

7. I disagree. I think the capacity to learn across domains is itself a skill. The question is how to demonstrate it without looking scattered. My answer, for now, is this site. I will write about what I am doing and why. The reader can judge.

8. The site is minimal because I have nothing to hide behind. If the writing is not interesting, no amount of design will fix it.

9. Let us see how long this one lasts.
